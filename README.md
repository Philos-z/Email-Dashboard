# Email Dashboard

A self-hosted email progress dashboard with a priority board, timeline, mail history, manual edits, SQLite storage, and an AI assistant. The interface uses Chinese. Noto Sans SC and Playfair Display fonts are bundled with their SIL Open Font Licenses.

This repository is a **sanitized application baseline**. It starts empty and contains no personal emails, project history, credentials, databases, logs, or account configuration. Existing private installations must keep their runtime data outside Git.

## Run the baseline

Requires Python 3.11+ and a signed-in Codex client with an Outlook MCP connection for email refresh.

```sh
python3 build_frontend.py
./start.sh
```

Open http://localhost:8765. Automatic email refresh starts paused. Configure the local OpenAI-compatible model proxy in Data & Settings before refreshing mail. The baseline uses a local API proxy; the `feature/personal-email-setup` branch adds per-installation Outlook/Gmail setup and custom HTTPS model endpoints.

To require a dashboard password, run `ATLAS_REQUIRE_LOGIN=1 ./start.sh`. The baseline launcher binds to the local network; use `ATLAS_BIND=127.0.0.1 ./start.sh` for local-only access. Keep the dashboard on a trusted network.

## Development

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/python -m pytest -q
node --test tests/*.cjs
```

Tests use synthetic projects only. `web/dashboard_lan.html` is generated by `build_frontend.py`; edit the source modules and rebuild.
